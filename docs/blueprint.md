# **App Name**: ATSResumeScan

## Core Features:

- Resume Upload & Content Parsing: Allows users to upload resumes (PDF/DOCX) via a drag-and-drop interface. The system then parses the document to extract essential content such as skills, experience, education, and keywords for further analysis.
- AI ATS Compatibility Analysis Tool: An AI tool that analyzes the parsed resume against Applicant Tracking System (ATS) standards, generating a comprehensive compatibility score (out of 100). It provides detailed feedback on formatting, keyword density, readability, structure, and skill alignment.
- AI Job Description Matching Tool: Users can paste job descriptions for specific roles. The AI tool compares the job description with the uploaded resume, identifying keyword matches, missing skills, and providing a match percentage score with actionable optimization recommendations.
- AI Resume Optimizer Tool: An AI tool that offers one-click resume improvements. It can rewrite weak bullet points, improve professional wording, suggest better ATS formatting, quantify achievements, and enhance action verbs with AI-generated suggestions.
- User Authentication & Dashboard: Secure user registration and login functionality (Google & Email/Password). A personalized dashboard allows users to manage uploaded resumes, track historical scan results, and download optimized files, all powered by Supabase.
- Freemium & AdSense Monetization: Implementation of a freemium model with basic usage limits for free users, integration of Google AdSense placeholder sections, and a modal for premium upgrades with outlined pricing plans (Basic vs. Pro features).
- SEO-Optimized Content Blog: A basic, SEO-friendly blog system for publishing articles related to ATS and career advice. It includes dynamic metadata, SEO-friendly URLs, and structured schema to attract organic traffic and support content marketing efforts, utilizing Supabase for content storage.

## Style Guidelines:

- Light/Dark Mode: The application will primarily feature a dark scheme, reflecting a modern tech aesthetic and providing a premium feel.
- Primary color: A vibrant, electric blue (#4d66ff) symbolizing innovation, professionalism, and energy. (HSL: 220, 80, 60)
- Background color: A very dark, desaturated blue-gray (#21262b) that establishes a deep, professional base, providing excellent contrast for UI elements. (HSL: 220, 15, 15)
- Accent color: A bright, clear lavender-purple (#bb80ff) chosen as an analogous hue from the blue-purple range to ensure good visual contrast and dynamism without venturing into forbidden 'teal' territory. (HSL: 250, 90, 70)
- Headline font: 'Space Grotesk' (sans-serif) for a modern, slightly techy, and bold statement suitable for a contemporary SaaS platform.
- Body font: 'Inter' (sans-serif) for high readability and a clean, neutral professional appearance, effectively complementing the headline font for extended content blocks.
- Utilize sleek, minimalist line-art or subtly filled icons that support a premium, contemporary SaaS look. Incorporate 'glassmorphism' styled cards for key information display, enhancing visual depth and aligning with a modern UI/UX.
- Implement a modern, intuitive dashboard layout with clear sectioning and streamlined navigation. Prioritize a mobile-first responsive design, ensuring optimal user experience and accessibility across all device sizes.
- Integrate smooth, subtle animations for UI transitions, interactive element hovers, and data visualization (e.g., animated ATS score progress bars). Include loading states and skeleton loaders to enhance user perception of speed and interactivity, contributing to a polished user experience.
